# LandBar v0.8.1

修复 Gemini 额度后台刷新时偶尔弹出 Windows 终端的问题。插件发起的 Antigravity CLI 查询会跳过 CLI 的后台自更新。

## 更新

退出旧版，完整解压 Windows x64 ZIP，运行 `安装并启动.cmd`。新版启动时会自动更新原版 v0.8.0 已安装的 Gemini 示例脚本，沿用原有启用状态和组件位置。自行修改过脚本的用户可按示例说明更新。 [安装说明](https://github.com/LeoAndJellyfish/LandBar/blob/v0.8.1/docs/installation.md) · [Gemini 示例](https://github.com/LeoAndJellyfish/LandBar/tree/v0.8.1/samples/gemini-balance)
