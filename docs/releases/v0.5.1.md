# LandBar v0.5.1

本版修复部分播放器显示旧封面及媒体会话读取失败的问题。

## 媒体封面

- 歌曲信息保持不变时，仍同步播放器更新的封面。
- 切歌后封面延迟到达时，自动替换先前的图片。
- 封面按图片内容独立缓存，多个会话的同名歌曲可使用各自的封面。
- 新缓存文件完整写入后再供界面读取，重复图片沿用已有文件。
- 修复多个播放器同时存在时，部分媒体来源因线程错误无法显示的问题。

## 验证

121 项稳定检查与 24 项真实媒体集成检查通过，涵盖封面更新、双会话独立控制、STA 调用和退出清理。旧实现对照可复现同曲封面未刷新的问题。

## 安装

完整解压 `LandBar-v0.5.1-win-x64.zip`，运行 `安装并启动.cmd`。更新前退出旧版，现有插件与配置保留。首次安装要求见 [安装说明](https://github.com/LeoAndJellyfish/LandBar/blob/v0.5.1/docs/installation.md)。

ZIP 校验值见 `SHA256SUMS.txt`。支持 Windows 10 2004 及以上版本、Windows 11 x64，自带 .NET 运行时。
