# LandBar v0.6.0

本版增加插件左右侧位置设置，并将 Codex 额度插件加入公开示例。

## 插件位置与排版

- 侧边组件必须声明默认位置和允许的侧边，支持固定左侧、固定右侧或左右可选。
- 插件管理按声明提供位置按钮；移动组件时，兼容的组件交换位置，同一组件始终只显示一次。
- 宿主按实际尺寸分配左右轨道，主体保持居中；窄屏精简媒体内容，并在空间不足时隐藏完整组件。
- 像素伙伴支持左右切换。圆环文字按字形的实际可见边界居中，高 DPI 下继续使用文本抗锯齿。
- 圆环参与动画边界检查，避免扩宽期间提前显示、局部裁切。

## Codex 额度示例

在“控制中心 → 插件管理”安装 Codex 额度示例并手动启用，可查看套餐剩余额度、重置时间及额外积分，并选择侧边圆环的位置。

示例需要 Python 3.10+ 和通过 ChatGPT 登录的 Codex CLI，使用安装者自己的本机登录状态。发布包包含通用源码与清单，个人凭据、额度快照和本机设置保留在用户电脑。依赖与字段说明见 [示例 README](https://github.com/LeoAndJellyfish/LandBar/blob/v0.6.0/samples/codex-balance/README.md)。

## 升级现有插件

旧侧边视图须补齐 `placement` 声明，建议使用 `idle.widget`。已安装的示例源码保存在用户插件目录中，更新应用后按 [迁移说明](https://github.com/LeoAndJellyfish/LandBar/blob/v0.6.0/docs/plugins.md#旧版侧边插件迁移)替换源码，再重新启用。保持插件与视图 ID 后，原有有效位置绑定继续保留。

## 验证

151 项稳定检查通过，覆盖插件位置声明、Codex 合成 app-server 子进程、公开示例精确打包清单及原有核心测试。插件布局 74 项、Codex 页面 40 项、圆环像素对齐 32 项桌面检查通过；展开与收起的逐帧检查未发现内容裁切或中心锚点偏移。

本机额外验证了 Codex 登录查询成功及正常退出，验证记录仅保存成功状态，未记录额度值。

## 安装

完整解压 `LandBar-v0.6.0-win-x64.zip`，运行 `安装并启动.cmd`。更新前退出旧版。首次安装要求见 [安装说明](https://github.com/LeoAndJellyfish/LandBar/blob/v0.6.0/docs/installation.md)。

ZIP 校验值见 `SHA256SUMS.txt`。支持 Windows 10 2004 及以上版本、Windows 11 x64，自带 .NET 运行时。
