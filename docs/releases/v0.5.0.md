# LandBar v0.5.0

本版缩小展开面板，并扩展插件界面能力。

## 提示与交互

- 新媒体来源、切歌、播放与暂停仅更新状态，保持收起；手动展开后仍可查看和控制播放。
- 鼠标位于灵动岛可见范围内时暂停自动收起，移出后重新计算完整时长。
- 单媒体面板调整为 400×240 DIP，通知为 400×180，双卡为 680×240；控制中心与设置同步收紧间距，正文保留 14／15 字号。

## 插件界面

- 插件可创建多个独立标签并指定标题，更多标签可横向滚动；旧卡片插件按名称分别显示。
- 支持替换媒体、通知、控制中心、设置等页面，也可在收起态左右添加组件或替换主体。
- 声明式节点支持布局、文字、按钮、圆环和像素动画，保留现有卡片协议。
- 界面替换需在插件管理中选择“使用”；停止插件后自动回退，托盘菜单保留“插件管理（内置）”和“恢复内置界面”。
- 新增公开的像素伙伴示例，提供收起态动画、独立标签与配色操作。

协议和示例见 [插件开发文档](https://github.com/LeoAndJellyfish/LandBar/blob/v0.5.0/docs/plugins.md)。公开包仅包含计时器与像素伙伴两个示例；用户插件和个人配置保留在本机。

## 安装

完整解压 `LandBar-v0.5.0-win-x64.zip`，运行 `安装并启动.cmd`。首次安装未签名开发包仍需手动开启 Windows 开发者模式。更新前退出旧版，插件与配置目录保持不变。

ZIP 校验值见 `SHA256SUMS.txt`。支持 Windows 10 2004 及以上版本、Windows 11 x64，自带 .NET 运行时。
