# LandBar v0.7.1

本版修复活动标签在窗口缩窄、页面切换后被遮挡的问题，媒体、通知和插件页按当前选项居中展示。

## 修复

- 当前标签在可用标签区域居中。窗口宽度变化、标签标题更新后重新定位，修复旧横向滚动偏移残留导致“媒体”“专注计时”等标签离开视口的问题。
- 标签按钮按稳定标识更新，切换选项及刷新页面内容时保留已有按钮、当前选择和定位。
- 标签栏提供相邻导航箭头，滚轮可切换相邻标签。右侧操作区保持固定位置；到达首末标签时保留正文页码。
- 320 DIP 窄页面按实际视口限制标签按钮宽度，较长标题使用省略号，悬停可查看完整标题。
- 协调系统的焦点滚动与标签居中；键盘切换产生的焦点请求在页面淡入完成后执行。

## 验证

155 项稳定检查、75 项标签栏专项检查通过。专项覆盖 320、400、680 DIP 宽度和 100%、125%、150%、200% 缩放，以及实际滚轮、方向键和首末导航事件。

107 项插件界面及 70 项收缩模式检查通过。展开与收起回归的 995 个采样帧未发现内容溢出、裁切或锚点偏移，66 次原生命中检查通过。

## 更新

退出旧版，完整解压 `LandBar-v0.7.1-win-x64.zip`，运行 `安装并启动.cmd`。现有设置、插件配置及组件选择继续保留，插件协议保持兼容。

发布包提供 Windows x64 ZIP 与 `SHA256SUMS.txt`，自带 .NET 运行时。安装步骤见 [安装说明](https://github.com/LeoAndJellyfish/LandBar/blob/v0.7.1/docs/installation.md)。
