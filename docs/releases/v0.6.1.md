# LandBar v0.6.1

本版修复关闭侧边插件后的空占位，以及时钟与额度圆环数字的垂直偏差。

## 修复

- 左右组件分别计算实际宽度。关闭、停用或撤回一侧组件后，对应宽度与间距一并回收，剩余媒体和插件自动重排。
- 单个 28 DIP 组件的空闲胶囊宽度为 148 DIP；单媒体加右侧圆环为 216 DIP。
- 整个岛继续围绕屏幕顶部中心伸缩，停止和恢复插件时保持原生窗口位置。
- 时钟与圆环数字按可见字形边界垂直居中，兼顾不同字号和显示缩放；保留原有字体、字号和文本抗锯齿。

## 验证

152 项稳定检查、107 项插件界面检查与 21 项空闲形态检查通过。192 组时钟／圆环像素检查覆盖 100%、125%、150%、200% 缩放，各自距共同行中心最多 0.5 个物理像素。原有 32 项圆环检查通过，展开与收起的 1020 个采样帧未发现裁切或锚点偏移。

## 更新

退出旧版，完整解压 `LandBar-v0.6.1-win-x64.zip`，运行 `安装并启动.cmd`。现有设置、插件开关与位置绑定继续保留。v0.6.0 插件可继续使用，旧版侧边插件的迁移说明见 [插件文档](https://github.com/LeoAndJellyfish/LandBar/blob/v0.6.1/docs/plugins.md#旧版侧边插件迁移)。

发布包提供 Windows x64 ZIP 与 `SHA256SUMS.txt`，自带 .NET 运行时。首次安装要求见 [安装说明](https://github.com/LeoAndJellyfish/LandBar/blob/v0.6.1/docs/installation.md)。
