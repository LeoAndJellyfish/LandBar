# LandBar v0.7.0

本版新增收缩模式，常态可仅显示一个所选组件：时钟、播放器封面或插件组件。

## 收缩模式

- 在“控制中心 → 设置”开启“收缩模式”，选择常态保留的组件。该模式默认关闭，选择与普通布局的左右侧绑定分别保存。
- 时钟使用 84 × 44 DIP 胶囊；播放器封面和 28 DIP 额度圆环使用 44 × 44 DIP 外壳。较宽、较高的插件组件按实际内容尺寸排版，并保留圆角边距。
- 多个媒体来源共用现有首选规则，收缩状态显示一个来源的封面；暂停播放后继续保留该组件。
- 所选媒体或插件暂时不可用时显示时钟，来源恢复后自动切回。关闭收缩模式后恢复原有布局。
- 点击播放器进入媒体页；点击插件组件及其外壳留白时，优先进入该插件的标签页。新通知继续按原有方式弹出，收起后恢复所选组件。

## 插件协议

- `idle.widget`、`idle.left`、`idle.right` 和 `idle.content` 默认支持独立显示，无需先绑定普通布局的位置。
- 视图可通过顶层布尔字段 `allowStandalone: false` 退出独立组件选择。活动标签及页面替换视图禁止声明该字段。
- 宿主握手增加 `standaloneWidgets` 能力标记，协议版本继续使用 `1`。已有组件省略新字段即可继续使用。
- `placement` 的左右位置限制继续用于普通布局。像素伙伴和 Codex 额度示例已增加明确的组件标题及独立显示声明。

完整规则见 [插件开发文档](https://github.com/LeoAndJellyfish/LandBar/blob/v0.7.0/docs/plugins.md#收缩模式与独立组件)。

## 验证

155 项稳定检查、70 项收缩模式桌面检查通过。收缩检查覆盖 100%、125%、150%、200% 缩放，2092 个可见采样帧未发现裁切、锚点偏移或原生窗口尺寸变化。

21 项空闲形态、107 项插件界面及 192 组时钟／圆环像素检查通过。原有展开与收起检查的 1002 个采样帧未发现内容溢出、裁切或锚点偏移，66 次原生命中检查通过。

## 更新

退出旧版，完整解压 `LandBar-v0.7.0-win-x64.zip`，运行 `安装并启动.cmd`。现有设置、插件开关及左右位置绑定继续保留，更新后可自行开启收缩模式。

v0.6.x 插件可继续使用；更早的侧边插件按 [迁移说明](https://github.com/LeoAndJellyfish/LandBar/blob/v0.7.0/docs/plugins.md#旧版侧边插件迁移)补齐位置声明。已安装的示例源码保留原样，需使用新版示例时先保留本地修改副本，再更新源码。

发布包提供 Windows x64 ZIP 与 `SHA256SUMS.txt`，自带 .NET 运行时。首次安装要求见 [安装说明](https://github.com/LeoAndJellyfish/LandBar/blob/v0.7.0/docs/installation.md)。
