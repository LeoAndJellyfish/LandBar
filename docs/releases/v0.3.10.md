# LandBar v0.3.10

Windows x64 桌面版本，包含 .NET 10 运行时与 Noto Sans SC 字体。

## 下载与安装

下载 `LandBar-v0.3.10-win-x64.zip`，完整解压至固定目录，运行 `安装并启动.cmd`。首次安装使用未签名的开发版身份包，需要先在 Windows 设置中手动启用开发者模式。脚本会检查状态，随后注册通知身份并启动程序。

进入“控制中心 → 设置”授权 Windows 通知访问。媒体信息来自 Windows 系统媒体会话；应用向 Windows 通知中心提交的消息可进入灵动岛。

## 当前功能

- 通知与切歌提示最多两条并列，更多提示轮换展示。
- 多个媒体来源分别控制上一首、播放／暂停和下一首。
- 无操作自动收起可选 1–5 秒或“永不”。
- “通知”页支持清空已接收和等待展示的消息，保留媒体状态。
- 托盘显示 LandBar 名称，托盘、窗口与程序文件使用统一图标。
- 预览示例与真实通知隔离；预览结束后恢复真实来源。

## 接入范围

微信或 QQ 使用自绘浮窗、任务栏红点、闪烁和声音时，消息正文需另行适配；当前版本通过 Windows 通知中心接收通知，尚未提供微信专用正文通道。

## 校验

`SHA256SUMS.txt` 提供压缩包的 SHA-256。下载后可在 PowerShell 中运行：

```powershell
Get-FileHash .\LandBar-v0.3.10-win-x64.zip -Algorithm SHA256
```
