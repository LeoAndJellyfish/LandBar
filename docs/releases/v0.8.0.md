# LandBar v0.8.0

本版新增 **Gemini 额度** 示例插件，可查看 Antigravity 账号中 Gemini 模型组的套餐剩余额度、重置时间和额外 AI 积分。

- 圆环显示已知额度窗口中最低的剩余比例，支持左右放置，也可在收缩模式下单独显示。点击圆环可打开 **Gemini** 标签。
- 标签页列出各额度窗口及额外积分，支持自动更新和手动刷新。登录失效时暂停自动查询，并在标签页内提示。
- 插件通过本机 Antigravity CLI 的只读命令获取数据，查询沿用 Windows 已配置的代理或终端代理变量。额度数据只在插件运行期间保存在内存中。

## 安装与更新

退出旧版，完整解压 Windows x64 ZIP，运行 `安装并启动.cmd`。在 **控制中心 → 插件管理** 点击 **Gemini 额度示例**，再启用插件。运行该示例需要 Python 3.10+、Antigravity CLI 1.1.11+ 和已登录的 Google 账号。 [Gemini 示例说明](https://github.com/LeoAndJellyfish/LandBar/blob/v0.8.0/samples/gemini-balance/README.md)

发布包含专注计时、像素伙伴、Codex 额度和 Gemini 额度四个示例，并附 `SHA256SUMS.txt`。 [安装说明](https://github.com/LeoAndJellyfish/LandBar/blob/v0.8.0/docs/installation.md)
