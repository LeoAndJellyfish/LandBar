# LandBar v0.4.0

本版调整空闲形态，并开放本地插件接入。

## 界面

- 无活动时显示 112×44 的居中时钟胶囊，移除消息占位图标。
- 媒体存在时显示实际封面与播放状态，保留顶部中心展开动画。
- 活动面板增加“插件”页，控制中心增加“插件管理”。

## 插件

- 使用独立进程和 UTF-8 JSON Lines 协议，支持 PowerShell、Python、C# 等语言。
- 插件可创建、更新、撤回活动卡片，显示进度，并提供最多三个操作按钮。
- 卡片与通知、媒体共用最多两张并列的提示队列；持续更新保留展示期限，收起后可从“插件”页查看。
- 每个插件需手动启用；停用、退出或协议错误时统一清理该会话的卡片。
- 附带专注计时器源码，支持暂停、继续、重置及十秒演示。

开发入口：[插件协议与示例](https://github.com/LeoAndJellyfish/LandBar/blob/v0.4.0/docs/plugins.md)。插件以当前 Windows 用户权限执行，请仅启用信任的本地程序。

## 下载与安装

下载 `LandBar-v0.4.0-win-x64.zip`，完整解压后运行 `安装并启动.cmd`。发布包自带 .NET 运行时，支持 Windows 10 2004 及以上版本和 Windows 11，架构为 x64。

当前采用未签名开发身份包，首次安装需手动开启 Windows 开发者模式。更新前退出旧版；插件与显示设置保存在 `%LOCALAPPDATA%\LandBar`，更新应用后继续保留。

ZIP 校验值见 `SHA256SUMS.txt`。微信消息仍以 Windows 通知中心实际输出为准，本版未加入独立微信正文适配。
