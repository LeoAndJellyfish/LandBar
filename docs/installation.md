# 安装与使用

## 系统要求

| 项目 | 要求 |
| --- | --- |
| Windows | Windows 10 2004（build 19041）及以上，或 Windows 11 |
| 架构 | x64 |
| 运行时 | 发布包已包含 .NET 运行时和字体 |
| 首次安装 | 当前未签名开发包需要 Windows 开发者模式 |
| 通知内容 | 来源应用需向 Windows 通知中心提交消息，并授予 LandBar 通知访问权限 |

## 首次安装

1. 打开 [最新 Release](https://github.com/LeoAndJellyfish/LandBar/releases/latest)，下载 Windows x64 ZIP。
2. 完整解压至长期保留的目录，例如 `D:\Apps\LandBar`。保留 `app`、`identity` 和启动／安装脚本之间的目录关系。
3. 在 Windows 设置中搜索“开发者模式”，按系统提示手动开启。安装脚本会检查该状态。
4. 双击 `安装并启动.cmd`。脚本为 LandBar 注册应用身份，然后启动悬浮栏。
5. 右键胶囊或单击托盘中的 **LandBar**，进入“控制中心 → 设置”，授予通知访问权限。

双击 `启动.cmd` 可再次运行。设置页可开启“登录 Windows 时启动”。媒体展示使用系统媒体会话，播放器提供会话后即可显示。

应用身份关联解压目录。移动目录后，在新位置重新运行 `安装并启动.cmd`。

## 更新

1. 从托盘菜单退出 LandBar。
2. 下载并完整解压新版本。
3. 在新版本目录运行 `安装并启动.cmd`，更新身份注册与运行路径。

显示设置位于 `%LOCALAPPDATA%\LandBar\settings.json`。通知历史保存在进程内存中，退出时清空。若已开启登录启动且更换了解压目录，在设置中关闭后重新开启该选项，更新启动路径。

## 验证下载文件

Release 同时提供 ZIP 和 `SHA256SUMS.txt`。在 PowerShell 中计算文件哈希，与同次 Release 的校验记录比较：

```powershell
Get-FileHash .\LandBar-v0.6.1-win-x64.zip -Algorithm SHA256
```

文件名应对应实际下载的版本。

## 通知与媒体

### Windows 通知权限

设置中的“Windows 通知”显示当前授权状态。未授权时点击“授权”；已关闭时可点击“打开设置”，在 Windows 设置中管理访问。成功状态显示“已授权”。

LandBar 读取应用实际提交到 Windows 通知中心的消息，从程序启动后新到达或更新的通知开始展示。“隐藏消息内容”控制岛内正文展示；“暂停弹出提示”暂停新提示。

### 微信、QQ 等应用

当前版本尚无微信正文的独立接入。应用自绘浮窗、任务栏红点、闪烁和声音使用其他渠道；应用若以这些方式提醒，相关正文需进一步适配。QQ 等应用的展示范围也取决于其实际系统通知输出。

### 媒体来源

播放器或浏览器需接入 Windows 系统媒体控制。LandBar 展示该会话提供的曲目、作者、封面与可用控制按钮。同一应用的多个会话分别保留，暂停某一来源后，其他来源保持原有状态。

### 无操作自动收起

在“控制中心 → 设置”选择 1、2、3、4、5 秒或“永不”。选择后即时生效并保存。鼠标位于灵动岛实际可见范围内时暂停倒计时，离开后重新计算完整时长。点击、滚动、键盘输入与新提示重新计时；媒体状态更新继续保持当前展开或收起状态。“永不”会保留展开状态，多条自动提示继续轮换。

### 示例插件

“控制中心 → 插件管理”可安装专注计时、像素伙伴和 Codex 额度示例。安装后手动启用；收起态组件另选左侧或右侧。Codex 示例需要 Python 3.10+、Codex CLI 和当前用户的 ChatGPT 登录，具体安装检查见 [示例说明](https://github.com/LeoAndJellyfish/LandBar/blob/main/samples/codex-balance/README.md)。

v0.6.0 的侧边插件必须声明支持位置。已安装的旧版像素伙伴等示例按 [迁移说明](plugins.md#旧版侧边插件迁移)更新，用户自行修改的源码应先保留副本。

### 清空消息与预览

“通知”页右上方的“清空消息”清理岛内已接收的通知历史和待展示通知，媒体继续保留。Windows 通知中心维持原有内容。新收到的通知仍可正常进入。

控制中心的预览使用标注“示例”的通知与媒体。预览队列独立，结束预览后恢复真实通知与媒体；在预览中清空消息仅清理示例。

## 卸载

从托盘菜单退出程序，然后运行解压目录的 `卸载.cmd`。脚本移除 LandBar 应用身份和登录启动项，保留程序文件与显示设置。卸载完成后可自行删除解压目录；清理个人设置时再处理 `%LOCALAPPDATA%\LandBar`。

## 签名分发

公开 Release 当前采用未签名的开发身份包。具备可信代码签名证书的构建者可按 [开发文档](development.md#签名构建)生成签名包，并使用 `Install.ps1 -SignedPackagePath <包路径>` 安装。证书信任与 Windows 安全设置由使用者管理。
